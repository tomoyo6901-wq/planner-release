# planner-release

**하루 계획표(planner) 앱 배포용 공개 저장소**입니다. 소스 코드는 비공개 저장소에 있고, 여기에는 가족이 받아 쓸 것만 둡니다.

- **Releases** — 서명된 안드로이드 앱 `planner-X.YYY.apk`. 앱의 설정 → 「업데이트 확인」이 토큰 없이 여기서 새 판을 찾습니다. 소스 저장소에 배포할 때 GitHub Actions 가 같이 올립니다.
- **`bible/krv.json`** — 개역한글(1961) 본문. 2012년에 저작권이 만료되어 누구나 쓸 수 있습니다. 앱의 성경 탭 「성경 받기」가 여기서 받습니다.

## 처음 설치 (가족)
1. 폰 브라우저로 이 저장소의 **Releases** → 맨 위 판의 `planner-X.YYY.apk` 를 내려받습니다.
2. 「이 출처의 앱 설치 허용」을 켜고 설치합니다.
3. 앱 → 설정 → 데이터 → **가족 공유**에서 가입한 뒤, 가족에게 받은 초대 코드를 넣고 「참여」.

이후 새 판은 앱 안 「업데이트 확인」으로 받습니다.
